1. APPLICATION STARTUP FIX (run_app.py)
--------------------------------------------------------------------------------
- Issue:
  When executing `python run_app.py`, the process hung indefinitely before 
  starting the Streamlit server.
- Root Cause:
  The legacy script attempted to run `setup_chromedriver.py` with stdout and 
  stderr redirected to /dev/null. The script got blocked attempting to download 
  and verify Google Chrome/Chromedriver binaries over the network.
- Solution:
  Removed the blocking `setup_chromedriver.py` call from `run_app.py`. Sothema 
  HR Intelligence is an internal ATS application that does not use Selenium or 
  Chromedriver (which were only part of the deprecated LinkedIn job scraper).
- Outcome:
  The application now starts immediately without blocking via:
    $ .venv/bin/python run_app.py
  or
    $ .venv/bin/streamlit run app.py

6. DATABASE LIFECYCLE: RAPID RESET, PURGE & DATASET REPLACEMENT
--------------------------------------------------------------------------------
- Date: 2026-11-04
- Need:
  The current 2,484 CV dataset (Kaggle scrape) is low quality (anonymized, noisy).
  Tools and UI options have been put in place to rapidly reset, wipe, or replace 
  the data with high-quality real resumes at any time:

- Option 1: 1-Click Purge from Web App UI
  * Navigate to: Paramètres -> Données locales -> "Réinitialisation & Purge de la base"
  * Click "Purger tous les dossiers de la CVthèque" and type PURGER to confirm.
  * Wipes all candidates, text, skills, and analyses in 1 second while keeping 
    the HR admin account (hrperson@sothema.ma) intact.

- Option 2: Instant Command-Line Purge Script (scripts/reset_db.py)
  * Run:
      $ .venv/bin/python scripts/reset_db.py
  * Clears candidate tables, preserves admin accounts, and vacuums SQLite in <1s.
  * Optional full wipe (including admin accounts):
      $ .venv/bin/python scripts/reset_db.py --all

- Option 3: Rapid Bulk Import of New / High-Quality Resumes
  * Place any new folder of PDF resumes in a directory (flat or categorized).
  * Run:
      $ .venv/bin/python scripts/bulk_import.py --data-dir path/to/new_cvs
  * Uses the high-performance pdftotext pipeline (>30 CVs/second, ~2,000 CVs in <80s).

- Option 4: Instant Database File Swapping
  * SQLite is a portable single-file database.
  * To start from a completely clean database:
      $ rm resume_data.db   # Automatically re-initialized on next app launch
  * To point to an alternative database:
      $ export SOTHEMA_DB_PATH=/path/to/other_database.db
      $ .venv/bin/streamlit run app.py
